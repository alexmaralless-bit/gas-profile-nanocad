# Нормативная база условных обозначений для профиля газопровода

## Основной вывод

ГОСТ 21.710-2021 задает состав чертежей наружных газопроводов и требования к планам/профилям, но не является полной библиотекой условных обозначений.

Для условной графики он отсылает к другим стандартам СПДС:

- ГОСТ 21.206-2012 - условные обозначения трубопроводов;
- ГОСТ 21.205-2016 - условные обозначения элементов трубопроводных систем и буквенно-цифровые обозначения сетей;
- ГОСТ 21.204-93 - условные обозначения элементов генеральных планов, сооружений транспорта и инженерных сетей;
- ГОСТ Р 21.302-2021 - условные обозначения инженерно-геологических выработок, грунтов и подземных вод, если на профиле нужны грунты/скважины;
- ГОСТ 2.303-68 - типы и толщины линий.

Для MVP плагина достаточно поддержать смысловую модель объектов и простые графические генераторы. Полную библиотеку условных знаков лучше делать второй очередью.

## Источники

Тексты стандартов в репозиторий не включены, на них даны ссылки по названию.

## ГОСТ 21.710-2021

Назначение для плагина:

- определяет состав рабочей документации наружных газопроводов;
- требует планы и продольные профили;
- задает, что продольный профиль является разверткой по оси газопровода;
- задает состав таблицы под профилем;
- требует показывать пересекаемые дороги, кюветы, коммуникации, сооружения, футляры, отметки верха трубы и глубину траншеи;
- вводит марки некоторых элементов газопровода.

Марки элементов из ГОСТ 21.710:

```text
ГК  колодец
КП  П-образный компенсатор
УП  угол поворота
Н   неподвижная опора
```

Также ГОСТ 21.710 указывает, что буквенно-цифровые обозначения газопроводов принимают по ГОСТ 21.205.

## ГОСТ 21.206-2012

Назначение для плагина:

- общие условные обозначения трубопроводов;
- упрощенные изображения трубопроводов и их элементов;
- правило: трубопроводы на схемах изображают одной линией;
- на чертежах трубопроводы можно показывать условно или упрощенно;
- если диаметр в масштабе равен 2 мм и более, трубопровод допускается/следует показывать двумя линиями.

Для нашего профиля:

- проектируемый газопровод в MVP можно показывать одной толстой линией как отметку верха трубы;
- режим `две линии` можно добавить позже для крупных диаметров или крупного масштаба;
- пересекаемые трубопроводы на профиле можно показывать упрощенным контуром по габариту и отметкам.

## ГОСТ 21.205-2016

Назначение для плагина:

- условные обозначения элементов трубопроводных систем;
- арматура, компенсаторы, вставки, опоры, направления потока и т.п.;
- буквенно-цифровые обозначения трубопроводов разных систем.

Важные буквенные обозначения систем:

```text
В  водоснабжение
К  канализация / водоотведение
Т  теплоснабжение и тепловые сети
Х  холодоснабжение
А  воздухоснабжение / вакуумные сети
Г  газораспределение и газопотребление
```

Газопроводы по ГОСТ 21.205:

```text
Г1  газопровод низкого давления до 0,1 МПа
Г2  газопровод среднего давления св. 0,1 до 0,3 МПа включ.
Г3  газопровод высокого давления св. 0,3 до 0,6 МПа включ.
Г4  газопровод высокого давления св. 0,6 МПа
Г5  газопровод продувочный
Г6  трубопровод на разрежение
Г7  газопровод / трубопровод безопасности
```

Для плагина это означает:

- `GP_NAME` пересечения должен хранить именно буквенно-цифровое обозначение, например `В1`, `К1`, `К2`, `Т1`, `Г3`;
- для проектируемого газопровода нужно хранить `PIPE_CODE`, например `Г1`, `Г2`, `Г3`;
- тип сети (`GP_TYPE`) нужен для логики, а обозначение (`GP_NAME`) нужно для чертежа.

## ГОСТ 21.204-93

Назначение для плагина:

- обозначения элементов генеральных планов;
- транспортные сооружения;
- инженерные сети на генпланах;
- водоотводные сооружения: лотки, кюветы, канавы, трубы, дренаж.

Для нашего профиля и развернутого плана это важно из-за:

- автомобильных дорог;
- железнодорожных и трамвайных путей;
- кюветов;
- лотков;
- водопропускных труб;
- существующих и проектируемых инженерных сетей.

Практическое правило для MVP:

- на плане мы не обязаны генерировать полную графику ГОСТ 21.204;
- если пользователь ставит системный блок пересечения на плане, атрибут `GP_TYPE` определяет, как объект будет показан на профиле и в развернутом плане;
- для дорог и кюветов на профиле достаточно упрощенного очертания и подписи, потому что ГОСТ 21.710 допускает упрощенные контурные очертания пересекаемых сооружений.

## ГОСТ Р 21.302-2021

Назначение для плагина:

- условные обозначения инженерно-геологических выработок;
- грунты;
- подземные воды;
- геологические колонки и разрезы.

Для MVP не нужен.

Нужен во второй очереди, если потребуется:

- показывать скважины на профиле;
- показывать уровень грунтовых вод;
- добавлять грунтовую колонку;
- показывать данные о грунтах по трассе.

## ГОСТ 2.303-68

Назначение для плагина:

- типы линий;
- соотношение толщин линий;
- сплошная толстая основная;
- сплошная тонкая;
- штрихпунктирная и другие линии.

Для профиля:

- проектируемый газопровод - сплошная толстая основная;
- фактическая земля - сплошная тонкая;
- проектная земля, если есть - сплошная толстая;
- пересекаемые сооружения и коммуникации - сплошная тонкая;
- уровень грунтовых вод - тонкая штрихпунктирная.

## Набор обозначений для MVP

### На плане

Плановые исходные объекты:

```text
GASPROF_CROSSING_POINT
GASPROF_PIPE_NODE
GASPROF_CASE
```

Графически они могут быть простыми. Смысл хранится в атрибутах.

### На графике профиля

Генерировать кодом:

```text
GROUND_EXISTING     фактическая земля, тонкая линия
GROUND_DESIGN       проектная земля, толстая линия, если есть
PIPE_DESIGN         проектный газопровод, толстая линия верха трубы
CROSSING_PIPE       пересекаемый трубопровод, контур/окружность/прямоугольник
CROSSING_CABLE      кабель, вертикальная линия/условный малый знак с подписью
ROAD                дорога, контур покрытия/границы
DITCH               кювет/канава, упрощенный V-образный или трапециевидный контур
CASE                футляр на газопроводе
WELL/PIPE_NODE      колодец, ковер, КИП, врезка
GROUNDWATER         грунтовые воды, штрихпунктирная линия, второй этап
BOREHOLE            скважина, второй этап
```

### В строке `Развернутый план`

Генерировать кодом:

```text
ROUTE_AXIS          горизонтальная ось по пикетажу
UP                  угол поворота с подписью УП1, УП2
TURN_ANGLE          значение угла поворота
CASE                футляр скобкой/двойной линией с подписью
PIPE_NODE           ГК, ковер, КИП, врезка
CROSSING            пересечение коротким штрихом с подписью
ROAD_WIDTH          дорога/проезд с шириной
DITCH               кювет/канава
```

## Футляр в развернутом плане

Футляр не нужно делать динамическим блоком.

Его проще и надежнее генерировать кодом:

```text
ось газопровода    -----------------------------
футляр                [==================]
подпись                Футляр Ø325x5; L=23,00
```

Данные:

```text
GP_TYPE = CASE
GP_CHAINAGE_START
GP_CHAINAGE_END
GP_LENGTH
GP_DIAMETER
GP_WALL
GP_MATERIAL
GP_NOTE
```

Если задан центр и длина:

```text
start = center - length / 2
end   = center + length / 2
```

Если заданы начало и конец:

```text
length = end - start
```

## Рекомендация по динамическим блокам

Динамические блоки не делать ядром плагина.

Использовать:

- простые атрибутные блоки на плане;
- кодогенерацию условной графики на профиле;
- кодогенерацию строки `Развернутый план`;
- опциональную библиотеку красивых блоков во второй очереди.

Это соответствует инженерной логике: расчетная модель должна быть устойчивой, а оформление можно улучшать поверх нее.
